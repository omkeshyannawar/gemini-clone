# Gemini AI Clone 2.0 [Gemini Lite] ✨

A sleek, responsive, and functional clone of the Google Gemini web interface. This project demonstrates modern frontend development practices, including API integration, and mobile-first design.

## 🌟 Key Features
* **Real-time AI Chat**: Powered by the Google Gemini 1.5 Flash API.
* **Web Grounding**: Integrated `Google Search` tool for up-to-date information (IPL scores, news, etc.).
* **Persistent Conversations**: Uses `localStorage` to save your chat history even after refreshing the page.
* **Secure API Handling**: Implemented `.env` architecture to keep API keys hidden from the public.
* **Fully Responsive**: A "Zen-mode" UI that works perfectly on Desktop, Tablet, and Mobile.
* **Markdown Support**: Beautifully renders AI responses including code blocks, lists, and bold text.

## 🛠️ Tech Stack
* **Frontend**: React.js (Vite)
* **Styling**: Custom CSS3 (Flexbox & Grid)
* **API**: Google Generative AI (Gemini API)
* **Tools**: React-Markdown
